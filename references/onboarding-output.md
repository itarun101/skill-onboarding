# Onboarding response format

Use the sections that fit the request; omit empty sections.

## What this skill does
In one or two sentences, explain its purpose and ideal use case.

## Before you install
List confirmed prerequisites and missing information that affects compatibility or destination.

## Install steps
Number each action. State where it happens, the command or UI action, and what success looks like. Separate completed actions from steps the user still needs to take.

## Verify and start using it
Give a documented check that the agent can discover or load the skill, then suggest a useful first invocation. Do not imply verification happened unless performed.

## Decisions or caveats
Mention relevant constraints, unresolved docs, access needs, and potential conflicts. Attribute claims to the inspected files where possible.

## Next actions
End with one to three next steps. If the user needs to continue in another agent, include a paste-ready prompt.
