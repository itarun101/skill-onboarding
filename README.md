# Skill Onboarding

A Codex skill that reads an agent skill’s instructions and guides, explains what it does, and prepares tailored installation, verification, and adoption steps.

## Use

Give your agent a skill folder, repository, archive, or URL and ask it to explain or help install the skill.

## Install

Place the `skill-onboarding` folder in a skill directory supported by your agent. For Codex, follow the current skill installation instructions in the [Codex documentation](https://developers.openai.com/codex/skills/).

## Contents

- `SKILL.md` — onboarding workflow
- `references/onboarding-output.md` — suggested response structure
